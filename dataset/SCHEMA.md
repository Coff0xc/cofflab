# dataset schema

Machine-readable exports of the cofflab catalog. Generated by
`gen_catalog.py` on every run, from the same records as `catalog.json`
— never hand-edited. One row per entry in every file.

## Files

- `cofflab.jsonl`: one JSON object per line, same records as
  `catalog.json` `items` (same fields, same order).
- `cofflab.csv`: the same records as flat columns (see below).
- `catalog.json` (repository root): the canonical machine-readable
  catalog, with `generated`, `kev_catalog_version`, `entries`,
  `items`.

## Fields

| Field | Type | Meaning | Source |
| --- | --- | --- | --- |
| id | string | CVE or GHSA identifier, also the entry directory name | meta.yaml `id` |
| category | string | one of web, ai, net, runtime, db, os | meta.yaml `category` |
| product | object {en, zh-TW} | product name, English and Traditional Chinese | catalog tables / meta.yaml |
| score | string | CVSS scores, `version score (source)` joined by `; `, or `unknown` | meta.yaml `cvss` |
| affected | string | affected versions | meta.yaml `affected` |
| fixed | string | fixed versions | meta.yaml `fixed` |
| cvss | list | CVSS entries {version, score, source} | meta.yaml `cvss` |
| cwe | list of string | CWE identifiers | meta.yaml `cwe` |
| demonstrated | list of string | what the PoC demonstrates | meta.yaml `demonstrated` |
| public_rce | bool | public remote code execution PoC exists | meta.yaml `public_rce` |
| review_executed | bool | any source was executed in an isolated environment | SOURCE.yaml `review.executed` |
| repro | string | Pending, Partial, No target, or Full | repro-status.json |
| verified | bool | `review_executed` OR `repro == Full` (derived, never stored) | derived |
| kev | bool | in the CISA Known Exploited Vulnerabilities feed | CISA KEV feed |
| in_the_wild | bool | named in the curated exploitation-reports file | in-the-wild reports file |
| epss | object or null | {score, percentile, date} | FIRST EPSS API writeback |
| tags | list of string | category + kev / in-the-wild + CWE-derived type tags | derived |
| collected | string | collection date | meta.yaml `collected` |
| sources | list | {id, upstream, license} per source | SOURCE.yaml |

## CSV notes

Multi-value fields (`cwe`, `demonstrated`, `tags`, `sources`) are
semicolon-joined. `epss_score` / `epss_percentile` are empty when the
entry has no EPSS value. Booleans render as True / False.
